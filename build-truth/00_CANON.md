# 00 — Canon

Canonical name: **CALI Runtime Federation (CALI-CRF)**.

Canonical role: distributed runtime federation and execution control plane for CALI runtime bodies inside the Ghost Atlas / Vishvarupa organism.

CALI-CRF federates existing systems. It is not a replacement build for Packet OS, JANUS, EDEN, Workforce Spine, MetaForge, DevOS, SECA, Thoth, ProofGrid, Medusa, or CrownGrid.
