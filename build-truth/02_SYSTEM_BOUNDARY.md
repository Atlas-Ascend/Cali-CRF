# 02 — System Boundary

CALI-CRF owns federation, runtime discovery, capability matching, assignment, dispatch, runtime health, execution-state aggregation, failure routing, and receipt normalization.

It does not own executive intent, durable memory, code generation, independent verification, proof storage, security policy, or infrastructure routing. Those remain JANUS/EDEN, Thoth, MetaForge, DevOS/SECA, ProofGrid, Medusa, and CrownGrid responsibilities respectively.
