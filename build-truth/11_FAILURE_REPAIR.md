# 11 — Failure and Repair

Failures are routed, not erased.

Categories:
- validation failure
- capability mismatch
- runtime unavailable
- execution failure
- verification failure
- receipt failure
- external dependency failure
- governance denial

Repair preserves original packet identity and attaches repair lineage. MetaForge produces bounded repair work; DevOS/SECA re-verify; CALI-CRF records transition history.
