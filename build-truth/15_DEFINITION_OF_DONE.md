# 15 — Definition of Done

CALI-CRF v0.1 is done when:
1. Packet schema validates structurally.
2. Four runtime manifests exist.
3. Scheduler selects compatible runtimes deterministically.
4. Assignment records are emitted.
5. State transitions reject invalid promotion.
6. Receipt generation requires evidence.
7. Failure routes are explicit.
8. CI runs typecheck, build, and tests.
9. Packet OS adapter contract exists.
10. A smoke path closes assignment through proof-bearing receipt generation.

Production promotion additionally requires deployed runtime health, integration evidence, and ProofGrid receipts.
