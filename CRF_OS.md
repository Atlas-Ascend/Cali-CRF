# CRF OS

CALI-CRF is the federation layer above individual CALI runtimes. It does not replace Packet OS, JANUS, EDEN, Workforce Spine, MetaForge, DevOS, SECA, Thoth, ProofGrid, Medusa, or CrownGrid. It coordinates bounded execution among them.

## Core law

No work is promoted as complete without an authorized packet, bounded assignment, execution result, verification outcome, and receipt.

## Control loop

1. Accept packet.
2. Validate schema and authority.
3. Resolve required capabilities.
4. Select CALI runtime body.
5. Dispatch bounded work.
6. Collect execution evidence.
7. Route verification to DevOS/SECA.
8. Repair through MetaForge when required.
9. Emit receipt and state transition.
10. Publish evidence to ProofGrid and memory to Thoth.
11. Return live state to JANUS/EDEN.
